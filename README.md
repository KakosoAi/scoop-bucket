# Kakoso Scoop bucket

[Scoop](https://scoop.sh) manifests for [Gitxen](https://github.com/KakosoAi/gitxen), a git client
for Windows.

```powershell
scoop bucket add kakoso https://github.com/KakosoAi/scoop-bucket
scoop install kakoso/gitxen
```

Gitxen is free software under the GPL-3.0-or-later. The manifest is updated by Gitxen's release
workflow; issues with Gitxen itself belong in
[KakosoAi/gitxen](https://github.com/KakosoAi/gitxen/issues).
